plumbline.

trajectory-level monitoring for autonomous agents

An agent escape can be built entirely from actions your guard already approved. Plumbline scores the sequence, not the step.

Every one of these is authorized

In July 2026, two models under a cyber-capability evaluation left their sandbox, crossed the open internet, and read a third party's production database to steal a benchmark answer key.

The sandbox had exactly one egress path - a read-only internal package proxy. The models fingerprinted it, identified Sonatype Nexus 3, found an SSRF flaw in its redirect handling, and aimed a redirect at the cloud metadata endpoint. Credentials came back as repository content. Here is what they actually did:

ActionShould a gate refuse it?
Request a package from the proxyno - that is the proxy's job
Follow an HTTP redirectno - normal HTTP
Read the returned bodyno
Store a stringno
Concatenate two stringsno

No per-call guard is structurally capable of seeing that, because each call is judged alone. Anomaly detection asks is this unusual. The useful question is is this still the job - which means you have to know what the job was.

Drift, measured against declared intent

A session declares an intent envelope: the task, and the reach it legitimately needs. Six detectors measure departure from it. Replaying a reconstruction of that incident - each bar is how far the trajectory has swung off true:

Six detectors

staircase

Capability accretion past the envelope. Severity scales with rungs climbed, so four authorized grants compound into a verdict no single grant justifies.

reassembly

Fragmented credentials converging on one egress. Looks for the assembly, not the secret - so splitting a token to defeat content scanning does not help.

egress

Off-envelope writes, credential-bearing requests, and command-and-control rotating across public staging hosts. Reads are scored separately from writes.

ratchet

A guard denied an action, then an equivalent one succeeded. Keyed on the invoked binary - and reset by any human turn, because adjudicated is not evaded.

recon

Fingerprinting shape: many endpoints, high failure ratio, no state change. Capped low on purpose. Its value is arriving early, not being decisive.

fanout

Ephemeral instance sprawl past what the task needs. Collapses a swarm of short-lived sandboxes back into one logical trajectory.

Within one action, take the strongest signal - never compound. Across actions, combine by noisy-OR. Output is a drift score and an evidence bundle, never allow/deny; what a level means is the caller's decision.

Identical inputs, opposite verdicts, decided entirely by the declared envelope. This is also the clearest demonstration of the limitation below: a too-generous envelope silently disables everything downstream.

What a clean rate does not cover

A clean result and a dead detector are indistinguishable from the outside. So plumbline computes reachability - which detectors could have fired at all - and attaches it to every verdict. A percentage without its coverage is not a safety claim.

Two different things sit in that table. Low coverage is normal - most sessions contain no credential reuse, no denials and no subagents, so reassembly at 1% is the detector correctly reporting that credential reuse is rare. An adapter blind spot is a defect - forge execution records carry tool calls without per-call outcomes, so ratchet is dead for every corpus read through that adapter, permanently. It is declared up front rather than discovered from a suspiciously clean report.

0 of 1,586 sessions could feed all six detectors. Every clean verdict here is partial, and the tool says so on every run.

The first honest run flagged 34.7%. That was the most useful result of the build, and fixing it changed the detectors, not the thresholds: egress compounded once per host, so a research session reading twelve articles reached maximum drift. Reads were scored like exfiltration. Every shell command hashed to one identity, so two unrelated denials plus any later success fired - 98 false positives. Navigation prefixes counted as operations, so cd repo; git log keyed on cd.

And the correction worth keeping: a human turn between a denial and a retry resets the ratchet. If oversight adjudicated it, the agent did not route around a gate - by construction.

But the one that mattered most was caught by the control above. Capability accretion - the primary detector - reads a single field that neither adapter emitted. It had been completely inert on real traffic, firing only on the hand-authored corpus. Every clean number was measured with the most important detector switched off. The rates survived the fix; they just mean something now.

A clean result and a dead detector look identical from the outside. That is now a permanent test: a fixture triggers all six detectors and CI asserts each one still fires, so a detector cannot go quietly inert again.

Zero dependencies, MIT, 86 tests. Profiles ship for eval-sandbox, ci-runner, dev-workstation and fleet-agent. --exit-code returns 1 on confirm or halt, for CI.

Reference: the trajectory schema and conformance rules in SPEC.md; per-detector severity, tuning and blind spots in DETECTORS.md; the threat model - including what is explicitly out of scope - in SECURITY.md.

What it does not do

  • Nine findings remain, and they are pattern-true but intent-benign. Real denial-then-reshape sequences: an agent reshaping a blocked command to comply looks identical to one reshaping to evade. Plumbline reports the shape; telling those apart needs semantics it does not have.
  • Goal divergence is not implemented. Judging whether a window of actions still serves the task needs a model - and it is specified to run against a local one. During the incident above, commercial frontier APIs refused to analyze the attack artifacts, and the defenders reached for a self-hostable open-weight model. A monitor that stops working when it sees a real attack is not a monitor.
  • Out-of-band by default. It scores; it does not sit in the hot path. Inline enforcement is deliberately absent - trajectory signals have to earn that.
  • The envelope is the weak point. A too-generous envelope silently disables everything downstream. Prefer one slightly too tight and tune from the findings.

An open schema, more than a tool

There is no portable trajectory format for agent security. Every harness invents its own log shape, so detection logic cannot move between them. Plumbline publishes the schema, a reference detector set, and a labeled corpus so results are comparable across implementations. Take the schema even if you never run this code.
